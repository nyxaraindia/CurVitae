## ✨ Features

- 🧠 **AI-Powered Resume Optimization** — Analyzes experience descriptions and refines phrasing for target roles using integrated AI.
- 🎨 **Dynamic Templates** — Choose from multiple ATS-friendly, professionally styled resume templates.
- 📱 **Cross-Platform** — Native UI performance for Mobile and Web built with Flutter.
- 🛡️ **Privacy-First Data Architecture** — Client-side data storage keeps sensitive personal history secure.
- 📊 **Skill Gap & Keyword Analysis** — Highlights missing skills and suggests high-impact verbs.
- 📄 **One-Click Export** — Export clean vector PDFs instantly.

## 🚀 Getting Started

### Prerequisites
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (v3.0.0 or higher)
* Dart SDK

### Setup & Run
```bash
# 1. Clone the repository
git clone [https://github.com/nyxaraindia/CurVitae.git](https://github.com/nyxaraindia/CurVitae.git)

# 2. Navigate to project directory
cd CurVitae

# 3. Install dependencies
flutter pub get

# 4. Run the application
flutter run
